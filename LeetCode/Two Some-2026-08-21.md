## Solution

```python
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        for i in range(len(nums)-1):
            for j in range(i + 1,len(nums)):
                if nums[i] + nums[j] == target:
                    return [i,j]

        return [0,0]
        
        
```

Better solution with hash
```python
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:  
        m = {}
        for i in range(len(nums)):
            missing = target - nums[i]
            if missing in m:
                return [m[missing], i]
            m[nums[i]] = i
```
