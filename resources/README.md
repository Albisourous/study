# Resources

## Coding practice
- [NeetCode 150](https://neetcode.io/practice) — best-organized pattern-based list, use this over raw "top 150 LC" lists
- [LeetCode](https://leetcode.com/) — for actually solving + timing
- Blind 75 (subset of NeetCode 150) if 3 weeks feels tight and you need to cut scope

## Mock interviews
- [Pramp](https://www.pramp.com/) — free peer mocks
- [interviewing.io](https://interviewing.io/) — paid, anonymous, real engineer interviewers
- A trusted friend/former colleague — arguably the best ROI, ask 1-2 people now

## System design
- [System Design Primer (GitHub)](https://github.com/donnemartin/system-design-primer)
- Alex Xu's "System Design Interview" Vol 1/2 — good for the deep-dive component patterns
